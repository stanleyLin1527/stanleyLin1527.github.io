# Personal Portfolio Website

A static personal portfolio website built with HTML, CSS, and JavaScript.

## Structure

```text
portfolio-site/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   ├── images/
│   └── files/
└── README.md
```

## Main Sections

- About Me
  - Introduction
  - Expertise
  - Languages
  - Interests summary
- Resume
  - Education timeline
  - Experience timeline
- Projects
  - 3–4 project cards
  - Presentation PDF link
  - Optional itch.io demo link
- Interests
  - Games
    - PC
    - PlayStation 4
    - Nintendo Switch
  - Music
    - Favorite Singers & Songs
    - Concert timeline
  - Anime
    - Poster grid with external links

## Local Preview

Open `index.html` directly in a browser, or use a simple local server.

For example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## GitHub Pages

For a user site repository named:

```text
<username>.github.io
```

push these files to the `main` branch and enable GitHub Pages if necessary.

## Replace Placeholders

1. Add the profile photo under `assets/images/`.
2. Replace social-media `href="#"` values.
3. Replace About Me filler text.
4. Replace Education and Experience timeline entries.
5. Add project cover images and presentation PDFs.
6. Add itch.io links only for projects that have a playable demo.
7. Replace game covers, singer photos, songs, concert history, and anime posters.
8. Replace anime `href="#"` values with Bahamut Anime, Netflix, or other viewing pages.
